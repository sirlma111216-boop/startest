# 나만의 별 이야기

중학교 3학년 과학 수업을 위한 학생 안내, 투닝 제작 가이드, 사전·사후 개념검사와 교사용 수업 설정 페이지입니다.

## 페이지

- `/`: 수업 시작
- `/guide`: 학생용 투닝 제작 가이드
- `/test`: 학생용 사전·사후 개념검사 8문항 초안
- `/teacher`: 교사용 수업 안내 설정 도구

Cloudflare Pages는 HTML 파일을 확장자 없는 주소로 제공합니다. 원본 파일은 모두 `public/`에 있습니다.

## Cloudflare Pages 배포

GitHub 저장소 `sirlma111216-boop/startest`를 연결합니다.

| 설정 | 값 |
| --- | --- |
| 프로덕션 브랜치 | main |
| 프레임워크 | None |
| 빌드 명령 | exit 0 |
| 빌드 출력 디렉터리 | public |
| 루트 디렉터리 | 저장소 루트(기본값) |

서버나 설치 작업이 필요 없는 정적 사이트입니다. 연결 후 main에 올라온 변경 사항이 자동 배포됩니다. [Cloudflare 공식 안내](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/)

## 현재 제공 범위

- 학생은 ChatGPT 로그인 없이 페이지를 이용합니다.
- 교사용 설정 화면도 공개 정적 페이지입니다. 비밀정보를 입력하지 마세요.
- 설정 화면은 새 학생 안내 링크 또는 설정 파일을 생성합니다. 서버 설정을 직접 변경하지 않습니다.
- 검사 결과는 학생이 CSV/JSON으로 내려받아 교사가 정한 비공개 경로로 제출합니다. 자동 수집·온라인 교사 결과 대시보드는 없습니다.
- 검사 참여코드는 사전·사후 응답을 연결하는 식별값이며 로그인 비밀번호나 투닝 보드 공유코드가 아닙니다.
- 검사 정답, 학생 자료, 계정 정보는 저장소와 공개 파일에 포함하지 않습니다.
- 검사판본은 STAR-CONCEPT-DRAFT-2입니다. 실제 검사 전에 교사가 검토하고 동일 판본으로 사전·사후 검사를 시행합니다.
- 총점·배점·마감일·반별 보드 주소는 추후 입력합니다.

## 발표 자료

`docs/`에는 NotebookLM용 슬라이드 프롬프트와 수행평가 안내 소스가 있습니다. 교사용 정답 자료는 별도로 보관합니다.
