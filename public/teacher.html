교사용 · 수업 안내 설정

총점·세부 배점·제출일·투닝 주소·반별 보드 주소를 나중에 입력하는 도구입니다. 입력 전에는 모두 ‘추후 안내’로 표시됩니다.

이 화면에서 설정한 내용은 자동으로 기존 사이트를 바꾸지 않습니다. 새 안내 링크를 만들어 학생에게 전달하거나, 설정 파일을 내려받아 사이트 업데이트에 사용할 수 있습니다. 생성한 링크에는 설정값이 들어가므로 비밀번호·학생정보는 적지 마세요.

교사·학생 페이지와 검사 결과

투닝 교사 학생관리 열기 · 투닝 보드 열기

현재 검사 결과는 자동 수집되지 않습니다. 학생이 검사 뒤 CSV 또는 JSON 답안을 내려받아 선생님이 지정한 비공개 경로로 제출해야 합니다. 이 화면은 수업 설정 도구이며 답안 관리 대시보드가 아닙니다. 학생 페이지와 주소는 분리되어 있지만 이 설정 화면도 공개됩니다. 여기에는 학생 답안이나 검사 정답이 없으며, 입력 내용은 이 브라우저에서만 처리합니다.

투닝 보드는 ‘보드 참가하기’에서 URL·공유코드로 참여합니다. 검사 참여코드는 사전·사후 답안을 연결하는 학생별 코드로, 보드 코드와 다릅니다.

반별 투닝 보드

학생에게 줄 안내 링크

현재 접속한 사이트 주소가 자동으로 들어갑니다. 학생은 ChatGPT 로그인 없이 안내와 검사 화면을 이용합니다.

새로 만든 학생용 안내 링크

새 링크의 내용이 맞는지 먼저 확인하세요. 이전에 배포한 링크에는 새 설정이 자동 반영되지 않습니다. 같은 링크를 계속 사용하려면 사이트 자체를 업데이트해야 합니다.

검사 초안 확정

검사 8문항은 교사용 정답·운영 안내와 함께 검토하세요. 문항 확정 후에는 설정 파일의 검사 상태를 변경하고 같은 판본으로 사전·사후를 실시해야 합니다. 수업 안내 링크만 바꾸는 기능은 검사 문항이나 판본을 바꾸지 않습니다.
